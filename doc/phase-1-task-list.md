# Phase 1 - Task List

## Mục tiêu
Hoàn thiện giao diện và chức năng cơ bản của trang web Personal Expense Manager để có thể sử dụng được đầy đủ trong môi trường local.

## Nhiệm vụ chính

### 1. Cải thiện giao diện người dùng
- [ ] Tối ưu bố cục trang chính
- [ ] Thêm các thành phần như header, form nhập chi tiêu, danh sách chi tiêu
- [ ] Cải thiện kiểu dáng bằng CSS cho dễ nhìn và responsive
- [ ] Thêm trạng thái loading và thông báo thành công/lỗi

### 2. Hoàn thiện chức năng CRUD
- [ ] Kiểm tra thêm khoản chi tiêu hoạt động đúng
- [ ] Kiểm tra xem danh sách chi tiêu hiển thị đúng
- [ ] Kiểm tra xóa khoản chi tiêu hoạt động đúng
- [ ] Xử lý lỗi khi nhập dữ liệu không hợp lệ

### 3. Tích hợp database ổn định
- [ ] Đảm bảo kết nối PostgreSQL hoạt động ổn định
- [ ] Kiểm tra schema và dữ liệu khởi tạo
- [ ] Thêm xử lý lỗi kết nối database rõ ràng hơn

### 4. Cải thiện trải nghiệm người dùng
- [ ] Thêm chức năng lọc theo danh mục
- [ ] Thêm chức năng tìm kiếm theo mô tả
- [ ] Thêm chức năng hiển thị tổng chi tiêu
- [ ] Thêm chức năng phân loại theo ngày/tháng

### 5. Chuẩn bị cho phát triển tiếp theo
- [ ] Viết thêm test cơ bản cho backend
- [ ] Tạo document hướng dẫn sử dụng cho người dùng
- [ ] Chuẩn bị cấu trúc cho các phase tiếp theo

## Kết quả mong đợi cuối Phase 1
- Trang web có thể thêm, xem và xóa chi tiêu một cách ổn định
- Giao diện thân thiện hơn và dễ sử dụng
- Dữ liệu được lưu đúng vào PostgreSQL
- Có nền tảng đủ vững để phát triển các tính năng nâng cao sau này
